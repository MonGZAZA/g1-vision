# Model Cards, Citations & Commercial Licensing

All newly trained models, datasets, and inference backends added to **G1 Vision** are selected to be **commercially permissive** (`BSD-3-Clause`, `Apache-2.0`, `MIT`, or `CC BY 4.0`).

---

## 1. Models Used in G1 Vision

| Component | Model / Artifact | Origin / Reference | License | Commercial Use |
| :--- | :--- | :--- | :--- | :--- |
| **Crowded Human & Pose Detector** | **Keypoint R-CNN (`ResNet50-FPN`) + `crowd_keypointrcnn_heads.pt`** | PyTorch / TorchVision (`torchvision.models.detection.keypointrcnn_resnet50_fpn`), fine-tuned on COCO 2017 crowded subset ($\ge 3$ people/frame) | **BSD-3-Clause** | **Yes** |
| **Temporal Gesture Classifier** | **GestureNet (`gesture_mlp.npz`)** | Custom 3-layer MLP trained from scratch on 36,000 3D$\rightarrow$2D kinematic upper-body sequences (`still`, `point`, `wave`) | **MIT** | **Yes** |
| **3D Pointing Direction Regressor** | **PointingDirNet (`pointing_dir_mlp.npz`)** | Custom 3-layer MLP trained from scratch on 30,000 3D$\rightarrow$2D pointing poses (cosine-similarity loss, $6.79^\circ$ median 3D error) | **MIT** | **Yes** |
| **Fallback Pose Detector** | **MediaPipe Pose Landmarker (`lite` / `full` / `heavy`)** | Google AI Edge / MediaPipe Tasks | **Apache-2.0** | **Yes** |
| **Face Detector & Head Yaw** | **YuNet (`face_detection_yunet_2023mar.onnx`)** | OpenCV Zoo (`opencv_zoo/models/face_detection_yunet`) | **MIT** | **Yes** |
| **Talking / Lip Blendshapes** | **MediaPipe Face Landmarker (`face_landmarker.task`)** | Google AI Edge / MediaPipe Tasks | **Apache-2.0** | **Yes** |
| **Gender & Age (Commercial Safe)** | **FairFace (`fairface.onnx`)** | Karkkainen & Joo, *WACV 2021* | **CC BY 4.0** | **Yes** (with attribution) |
| **Fine-Grained Age (Optional)** | **MiVOLO v2 (`mivolo_v2_age.onnx`)** | Layer6 / WildChlamydia (`MiVOLO`), pre-bundled in student pack (gitignored; $>100$ MB) | *Check upstream* | *Disabled/omitted automatically if file removed* |

> **Commercial Deployment Note**: `vision/vision/age_gender.py` automatically falls back cleanly if `mivolo_v2_age.onnx` is not present. To guarantee 100% commercially permissive deployment, simply omit `mivolo_v2_age.onnx` and rely on FairFace (`CC BY 4.0`), Keypoint R-CNN (`BSD-3-Clause`), GestureNet (`MIT`), YuNet (`MIT`), and MediaPipe Face Landmarker (`Apache-2.0`).

## 2. Datasets Used for Training

| Dataset | Usage | Origin / Reference | License | Commercial Use |
| :--- | :--- | :--- | :--- | :--- |
| **COCO 2017 (`val2017` Crowded Subset)** | Fine-tuning Keypoint R-CNN on crowded multi-person frames ($\ge 3$ people/image; 2,816 train / 618 held-out crowded val images) with occlusion & lighting augmentations | Lin et al., *Microsoft COCO: Common Objects in Context*, ECCV 2014 (`cocodataset.org`) | **CC BY 4.0** | **Yes** (with attribution) |
| **Synthetic 3D$\rightarrow$2D Kinematic Gesture Dataset** | Training & validating `GestureNet` (36,000 train / 6,000 val sequences across 0.9–4.5 m, $\pm 50^\circ$ yaw, foreshortened pointing, arm transitions, and hard negatives) | Generated by `vision/training/train_gesture.py` | **MIT** | **Yes** |
